# Changelog

All notable changes to **Toolbar Shortcuts** by Lumenwake are documented in this file.

## [1.0.0] - 2026-05-18

### Added

- Bootstrap Play toolbar controls with bootstrap / current scene targets.
- Configurable toolbar shortcuts (left / right) via `ToolbarShortcutsConfig`.
- Shortcuts Window for Window / Both placement shortcuts.
- Welcome window and one-click Setup on import.
- Unity 6 main toolbar overlay integration.
